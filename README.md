# Universidade Crescente

Site institucional da Universidade Crescente, localizado em Zango 3, Icolo e Bengo, Angola.

## Estrutura

- `Iniversidade crescente/` — site principal
- `image/` — imagens e recursos visuais
- `fix_images.py` — script auxiliar para ajuste de imagens

## Visualização local

Abra a pasta `Iniversidade crescente` ou execute um servidor local na raiz do projeto:

```bash
python -m http.server 8000
```

Depois acesse:

- http://localhost:8000/

## Publicação no GitHub Pages

Ative o GitHub Pages no repositório do GitHub usando a branch `main` e a pasta raiz.

A página principal inclui um redirecionamento para:

- `Iniversidade crescente/index.html`
